## About PACE

PACE is the official mental performance assessment system used by elite sports organizations to measure and optimize 13 key mental skills:

- Attention control
- Anxiety management
- Confidence
- Motivation
- Concentration
- Emotional regulation
- Goal setting
- Imagery
- Mental preparation
- Pressure tolerance
- Resilience
- Self-awareness
- Team focus
